# Cerebro

Cerebro is a personal, single-user tool built and used only by Santiago Lattuf (UpNova).
It keeps a private long-term memory (notes, work context and a daily assistant) and, with
the owner's explicit consent, can read his own Gmail and Google Calendar in read-only mode
so the assistant can summarize his day and remind him of meetings.

- It is not a public service: there are no other users, no sign-up and no data collection
  from anyone else.
- Access to Google data is read-only (gmail.readonly and calendar.readonly). Cerebro never
  sends, modifies or deletes email or events, and does not request contacts.
- Privacy policy: see [PRIVACY.md](PRIVACY.md)
- Contact: slattuf@upnovaag.com

Resumen en español: herramienta personal de una sola persona; lee su Gmail y su Calendar
solo en modo lectura para su asistente privado; no es un servicio público.

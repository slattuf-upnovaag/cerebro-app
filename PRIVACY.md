# Privacy Policy: Cerebro
Last updated: 2026-10-07

Cerebro is a personal application operated by Santiago Lattuf (the "owner") for his own
exclusive use. It has no other users.

## Data accessed
With the owner's consent through Google OAuth, and only for the owner's own Google
accounts, Cerebro reads Gmail messages (gmail.readonly) and Google Calendar events
(calendar.readonly). It does not access contacts and cannot send, modify or delete anything.

## How the data is used
Only to provide features to the owner: searching his own memory, a daily summary and
check-in, and meeting reminders. The data is not sold, not used for advertising and not
shared with third parties.

## Storage and security
The data is stored on the owner's own computer, plus private encrypted backups that he
controls. Only the owner has access.

## AI processing
To summarize content and answer the owner's questions, text from this data may be
processed by Anthropic's Claude AI service, under the owner's own account and Anthropic's
terms. Cerebro does not use Google user data to develop or train AI models.

## Google API Services User Data Policy
Cerebro's use and transfer of information received from Google APIs adheres to the Google
API Services User Data Policy, including the Limited Use requirements.

## Retention and deletion
Data stays until the owner deletes it. Access can be revoked at any time at
https://myaccount.google.com/permissions. To request deletion, write to slattuf@upnovaag.com.

## Changes
Any change will be reflected in this file with a new date.
